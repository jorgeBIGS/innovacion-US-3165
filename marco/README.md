# Marco común de alfabetización en IA

Esta carpeta contiene el marco acordado por la red y las fichas de calibración de cada
asignatura.

- `PLANTILLA-ficha-calibracion.md`: plantilla que rellena cada docente (actividad A2).
- Las fichas cumplimentadas se añaden aquí como `ficha-<asignatura>.md`.

El marco parte de las cuatro dimensiones de Ng et al. (2021) —conocer y entender, usar y
aplicar, evaluar y crear, y cuestiones éticas— y se alinea con los marcos de competencias
en IA de la UNESCO y de la OCDE/Unión Europea. Las referencias completas están en el
README del repositorio.
